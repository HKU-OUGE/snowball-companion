# 首次配置：用户留在网页

实体设备配置执行 [automatic-setup.md](automatic-setup.md)。从 Skill 使用 `open_console.py --setup` 打开并立即启动；不要打开网页就结束本轮，也不要另发语音、Pet、自启动的手动配置清单。用户在同一个网页选择、查看进度、重试和跳过；agent 继续检查本地步骤与真实账号 Pet 回执。

| 阶段 | 用户看哪里 | 实际完成依据 |
| --- | --- | --- |
| 自动配置 | 电脑网页 | 环境、自启动归属、Hub 与本地识别服务检查；Pet 经真实账号接口核验 |
| 连接雪球 | 电脑网页，保持 USB 接线 | 核对唯一 USB 串口；0.27.0+ 首次教程由安装程序通过串口自动开启配对并绑定，旧固件或已配置设备才要求本机确认；真实认证与新鲜遥测才算连接 |
| 确认同步 | 网页结果 | 插件事件、Hub、传输和设备回执分开核验；无任务可以显示等待新任务 |
| 操作练习 | 只看雪球 | 连接成功后自动进入顺序练习；不能跳步或中途跳过，手势成功后开心回应并自动下一步；教程不含摸摸或吃西瓜，练习题不发送 |
| 网络设置 | 网页 | Wi-Fi 可选；设备确认保存及实际联网才算成功 |

已有配对、有效模型、自启或当前账号 Pet 优先复用。不要因为教程重置设备或重复安装。设备限时配对只在电脑环境准备好后开启。设备路径为设置 → 更多 → 连接电脑；旧固件的「开始配对」和新固件的「开启配对」指同一操作。整卡 USB 存储或只读安装盘需退出并恢复串口后才能首次绑定。

若用户只看配置、打开控制台或要求编辑文档，不运行 `--setup`。若只想用账号 Pet，走 [pets.md](pets.md)，不要求设备、语音或登录后台。插件、共享服务、账号 Pet 和固件的生命周期仍分开；不批准 Hooks 或写 eFuse。网页圆屏演示是模拟，不能用于真实连接验收。

Windows 缺少回答能力时按 [windows-send.md](windows-send.md) 检查当前 Hub 的投递接口；识别服务就绪不证明真实问题已答复。用户未要求发送测试消息时不代发。
