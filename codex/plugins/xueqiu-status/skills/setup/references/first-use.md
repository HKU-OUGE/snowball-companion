# 首次使用：只沿着一条主线

实体雪球的配置主入口是**电脑上的雪球控制台**。每次引导只给当前一步，明确说
“现在看电脑控制台”“现在看雪球”或“回到 Codex 会话”，并说明做完回到哪里。
已有步骤核验通过就从下一步继续；不要为了教程清除配对、重新安装或重置进度。

| 阶段 | 用户看哪里、做什么 | 何时继续 |
| --- | --- | --- |
| 安装入口 | 在电脑固定目录安装对应插件；由 Setup 打开雪球控制台 | 确认插件注册和正确的控制台入口 |
| 01 准备电脑 | 看控制台，准备连接环境、启动连接服务 | 依赖就绪后再开启设备的限时配对 |
| 02 连接雪球 | 接 USB 数据线；看雪球的「连接电脑」，核对蓝牙名称并点「开启配对」；**回电脑控制台**核对串口并绑定 | 身份已保存，且收到实际蓝牙认证与新鲜设备遥测；已有有效绑定直接复用 |
| 03 确认同步 | 留在控制台看检查结果；需要真实事件时，明确提示回原 AI 会话正常使用，再回控制台检查；最后看雪球的会话列表 | 真实事件与设备状态一致。没有任务可显示「等待新任务」，不能注入假任务 |
| 设备练习 | 看雪球，连接后点「继续练习」，完成摸摸、吃西瓜、设置、会话、待答、状态的手势练习 | 操作成功由雪球回应并自动继续；练习题不发送，也不代表真实回答能力已就绪 |
| 04 可选功能 | 回电脑控制台，按需要配置 Wi-Fi；语音和账号桌宠在用户要求时再进入对应参考 | 基础蓝牙同步不依赖这些选项，不要求全部启用 |

设备首次教程在「连接电脑」停留时，用户可以先完成电脑准备；两分钟配对窗口过期后，
等电脑已准备好再点一次「开启配对」。旧固件可能写「开始配对」，指同一操作。
普通设备页面路径为「设置 → 更多 → 连接电脑」；首次教程已在此页时不必退出重找。
仅在 Windows 蓝牙设置中显示“已配对”不算完成应用绑定。USB 安装盘模式需先退出，
恢复串口后才能绑定。连接完成后，USB 不需要一直用于状态同步。

## 三个入口各管什么

- **控制台**：真实设备的依赖、USB 身份绑定、蓝牙、同步检查、可选 Wi-Fi。用
  [本地入口](local-console.md) 打开，不让用户记端口或启动开发服务器。
- **设备教程**：物理确认和触摸练习。不要在 360 像素屏幕讲安装命令、权限排错或输入密码。
- **AI 会话 / Setup**：安装插件、按宿主要求审阅 Hooks、排错和用户提出的可选功能。
  完成这些操作后明确带回控制台当前阶段，不另起一份完整配网教程。
- 开发用**网页圆屏演示**只是手势练习，不是真实控制台。点击「模拟连接」不能绑定设备。

## 连接完成不等于全部功能就绪

分开报告：插件已加载、真实事件已收到、蓝牙已认证、设备已同步。
Codex 的待答／追加指令还需投递通道可用；语音还需本地识别服务和模型。
没有真实问题时写“尚未实测回答”，不要生成测试问题、自动回答或宣称已通过。
缺少回答入口按 [Windows 投递通道](windows-send.md) 排错；录音不可用按
[语音配置](speech-setup.md) 继续。Claude / Cursor 不承诺 Codex 的回答和语音投递能力。

只要用户请求的是账号 Pet，就走 [桌宠操作](pets.md)，无需 USB、蓝牙、控制台或语音。
文档修改不执行安装；打开控制台不批准 Hooks，不注册登录任务，不刷固件。
安装和清理仍遵守 [生命周期](plugin-lifecycle.md)。
