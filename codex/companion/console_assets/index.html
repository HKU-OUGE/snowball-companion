FIRST, YOUR COMPUTER

先把电脑准备好

控制台已随插件安装。准备一次依赖，之后双击入口就能再次打开。

如果这台电脑已有雪球服务，会优先复用已有连接和配对。

首次准备需要联网下载 Python 依赖，可能需要几分钟。无需安装 Node.js。

环境准备好后，就可以与雪球见面了。

HELLO, SNOWBALL

连接你的雪球

第一次通过 USB 确认设备身份，以后由蓝牙自动连接。

已绑定的设备

这次可以复用配对信息。

  1. 接上 USB 数据线把雪球连接到这台电脑并开机。
  2. 在雪球开启配对设置 → 更多 → 连接电脑 → 开启配对。窗口持续两分钟。
确认绑定后，继续配置可选的 Wi-Fi。

A LITTLE MORE FREEDOM

让雪球连上 Wi-Fi

靠近电脑时继续用蓝牙。离开蓝牙范围后，可以通过 Wi-Fi 保持同步。

准备这台电脑的局域网入口

选择电脑与雪球所在局域网的地址。只为设备建立加密同步连接。

在雪球上打开设置 → 更多 → 连接电脑 → Wi-Fi 配网

保持页面打开，电脑就能安全传送配置。

Windows 连上 Wi-Fi 后仍无法同步？

请先确认电脑和雪球在同一局域网，家庭网络已设为“专用网络”。下面的操作只允许本安装的网关在专用网络接收局域网连接；Windows 会请求管理员确认。

可选：远程同步入口

跨互联网同步还需要电脑端的云连接服务与设备身份注册。此向导先完成局域网连接；填写地址不会自动开通云服务。

等待蓝牙和配网窗口

密码仅用于本次加密传输，不保存到网页、网址或安装包。

看到“配置已加密保存”后，再检查连接。

READY TO KEEP YOU COMPANY

看看是否都连接好了

配对、连接和状态同步分别检查，进展会在这里自动更新。

下次登录，也自动来陪你

在 Windows 登录后启动后台服务。电脑睡眠或关机时，服务会暂停。

自动模式下显示“蓝牙优先，Wi-Fi 休眠”是正常的。想立即验证 Wi-Fi，可在雪球的 Wi-Fi 页点击“优先 Wi-Fi”。
