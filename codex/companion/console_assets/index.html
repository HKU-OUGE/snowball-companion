准备就绪后再按以下步骤操作。设备首次教程已在“连接电脑”时，无需退出教程。

  1. 先在电脑接上 USB 数据线把雪球连接到这台电脑并开机。
  2. 现在看雪球：开启配对设置 → 更多 → 连接电脑 → 开启配对。核对蓝牙名称，窗口持续两分钟。
  3. 回电脑控制台：绑定刷新并核对下方串口，勾选后点“绑定这台雪球”。只在系统蓝牙里配对还不算完成。
绑定后先确认蓝牙和会话同步；Wi-Fi 可以稍后配置。

准备这台电脑的局域网入口

选择电脑与雪球所在局域网的地址。只为设备建立加密同步连接。

在雪球上打开设置 → 更多 → 连接电脑 → Wi-Fi 配网

保持页面打开，电脑就能安全传送配置。

Windows 连上 Wi-Fi 后仍无法同步？

请先确认电脑和雪球在同一局域网，家庭网络已设为“专用网络”。下面的操作只允许本安装的网关在专用网络接收局域网连接；Windows 会请求管理员确认。

设备上会练习什么？

连接确认后，在雪球点“继续练习”。依次试试摸摸、吃西瓜、滑动看设置、会话、待答和状态；做对后雪球会回应并自动继续。
