# 待答详情反向返回 · 0.18.2

根据用户澄清，问题是待答详情不能通过反向横滑回到主表盘。0.18.1只支持向右返回；本版补上向左返回，保留已有向右返回。正文、长选项、确认回答内容以及外围按钮上的有效水平滑动均回到主表盘，空列表也适用。表盘进入各页面的原有方向、设置页导航不变。

上下拖动继续阅读，先上下阅读再横向偏移时保持阅读。短距离、方向不明确或取消的手势不返回；拖动不选择或发送答案。返回只关闭页面，不回答或忽略问题。

网页在1440×1050鼠标与430×932触摸环境复现0.18.1反向不返回，修改后通过三种内容页反向返回、保留原方向返回、垂直阅读、方向锁定、取消手势、普通选项点击和确认按钮拖动；零真实写入、零控制台错误。通过142项网页逻辑、4项Sites及4组原生控制器/手势测试。

实机旧版的正文、选项、确认均复现问题，新版在相同USB输入路径全部通过。测试用隔离BLE问题，阻断答案和提醒投递，不向真实Hub注入测试事件。结束后恢复生产蓝牙，保留教程进度和显示设置。该测试为串口输入回放，不等于人手传感器验收；截图为软件重绘。仅更新app1（0x310000），保留原厂系统、NVS和SD资源。
