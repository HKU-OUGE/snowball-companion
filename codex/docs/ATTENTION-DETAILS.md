# 手表回答与会话进度（0.13.0）

表盘从左向右滑进入「待答详情」，详情内右滑回表盘。原来的上滑会话、下滑设备状态、左滑设置不变。息屏后的第一下触摸只唤醒，不提交答案。

## 回答问题

已接通本机 **Codex Desktop 的 `request_user_input_async` 普通问题**。点「选择答案」查看选项，选中后进入「确认回答」，再次点「确认发送」才发送到原聊天。确认前可返回修改。每个答案绑定具体会话、问题和选项，后台自动关注切换不会改写目标。

- 圆屏支持最多 6 个选项，每项最多 80 字符 / 240 UTF-8 字节。长选项在列表省略，确认页可滚动阅读完整选项；不截断文本后提交不同含义。
- 网页「待答」使用同一份真实问题，支持选择选项及最多 1000 字符的自由输入，均需确认。
- 自由输入问题、旧问题缺少回传身份、过长选项或不支持的来源，手表提示回电脑回答。
- Claude / Cursor 的回答接收接口、阻塞式 `request_user_input`、系统权限或工具执行批准尚未接通。普通问答不会调用权限批准接口。
- 只有电脑端明确接受后才显示「答案已发送」。断开、超时或结果不明显示未确认；不会自动重发。每条问题持久保存发送结果，避免设备连点、网络重连或服务重启后重复发送。
- 通过手表回答与在电脑上回答使用相同的结构化问题标识；真实回答触发原有 Hook 清除待答状态。暂缓/忽略仍然只管提醒。
- **已知限制：Codex Desktop 的问题输入框可能仍然保留。** accepted 只证明聊天接收答案，不证明 Desktop 收起问题框。当前安装版本在本地提交按钮的回调中单独结束问题输入界面，现用线程 IPC 没有对应接口；不能通过重复发送答案来补救。对于仅有这一条问题的输入框，可以手动点「跳过」收起，无需再次回答。多问题表单可能另有未提交的草稿，不应整体自动跳过。

## 提醒控制

「稍后处理」暂停这条问题的主动提醒 600 秒；普通 Hook、心跳和重复暂缓不延长原截止时间。「忽略提醒」按问题关闭主动提醒，但问题仍可查看和恢复。新问题不会继承旧问题设置。这些操作不会回答、批准或取消任务。

## 会话摘要

设备「查看会话」及会话列表中的详情，显示单行会话名、当前阶段及可滚动的最近进度。摘要来自助手已经发给用户的 commentary / final 消息，是有界文本摘录，不是内部推理，也不是新的模型生成。最多 256 字符 / 768 UTF-8 字节，截断明确加省略号；没有消息就显示「暂未提供进度摘要」。新一轮开始会清除旧一轮摘要，不拿旧结果冒充新进度。失去状态来源时仍明确显示同步异常。

网页「会话 → 查看本机会话」显示真实列表和摘要；原演示列表及拖动排序练习仍独立保留。真实列表此版本仅查看，不改变设备优先级。网页任务表盘和外围演示控制仍是模拟数据。

## 本机接收适配

`desktop/codex_desktop.py` 对当前本机 Codex Desktop 的私有窗口协作 IPC 做兼容适配：检查同用户、私有 Unix socket，按协议版本寻找原聊天的 owner，只发送用户确认的单条结构化问题回答。不修改 Codex 程序，不启动另一个会话，不转发 shell 命令，不改权限设置，不自动回退到另一聊天或远程主机。IPC 是本机版本相关接口，不是稳定公开 API；版本变化、无 owner 或明确拒绝时停止提交并提示回电脑。

进度读取只查询本机 SQLite 的会话 ID / rollout 路径，再对正在同步的会话增量读取最近日志。启动/文件跳跃最多读取末尾 2 MiB，单行上限 512 KiB；仅提取公开给用户的 assistant commentary / final，丢弃 reasoning、用户输入、工具输出与任意命令。没有额外模型请求。摘要采集不延长 AI 活动时间戳。

Hook 的私有记录新增原始问题路由、原文和选项，权限 0600，位于本机 `codex-adapter/hooks`。公开快照和 BLE 仍只用匿名身份、问题正文、选项和摘要。`answers.json` 仅保存问题标识、幂等请求 ID、时间与投递结果，不保存答案正文；原聊天会正常记录用户回答。

## 通信与兼容

BLE 紧凑 INFO v4 保留三份完整 HMAC，最大 512 字节。签名写版本 6 的 op4/op5 原子传递选项元数据和分片内容；反向 action6..11 表示明确确认的选项 0..5，绑定 nonce、序号、目录代次、会话及问题。旧提醒 action3/4/5 不变。新桥接仍可连接旧固件；不会向旧固件发送选项扩展。

版本 7 发送独立的摘要目录，复用有界原子文本解析器。内容不变时只续 20 秒租约，不重发全文；摘要元数据不刷新任务寿命、不触发状态声音。文字目录和选项缓存放 PSRAM，保持原有 180ms 自然切换和息屏/音频行为。

网页 `/api/answer` 通过服务器转发至固定回环 Hub `/v1/answer`。只允许同源回环 JSON、明确选择或文本、精确问题与幂等 ID；令牌不进入浏览器。不提供任意消息、命令或批准端点。
