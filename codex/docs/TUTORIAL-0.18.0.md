# 连贯的实用教程 · 0.18.0

教程改为在日常页面上逐步指导，顶部保留短提示。导航中间不再切回一张独立的宠物庆祝页，也不再为了每个小动作锁住操作1.8秒。完成整段练习后，雪球开心回应1800ms，再自动开始下一段。

## 六组引导

1. 认识与连接：欢迎后进入与日常相同的连接页，显示蓝牙名字；已连接也由用户确认继续，不突然自动离开。网页使用明确标注的模拟连接。
2. 摸摸与陪伴：使用日常表盘和同一尺寸的宠物，轻点回应；长按进入陪伴后保持在里面，体验后再长按返回。取消原来的1.2秒自动切走。
3. 熟悉设置：在实际设置布局里选择软件，再返回。设备保留“设置 → AI软件 → 选择 → 设置”的实际路径；网页复用其现有软件选择控件。练习选择不写回原来的关注软件。
4. 查看会话：列表 → 详情 → 返回列表 → 下滑回表盘。使用隔离的练习会话，展示“布置任务”和“创建新会话”的位置；教程不启动录音、不发送指令、不创建聊天。
5. 回答问题：真实的待答布局 → 选项 → 检查答案 → 确认练习。确认后留在原页面反馈，随后进入下一段；不会投递真实问题答案。
6. 状态与完成：下滑看实际状态页面，上滑返回；六种任务状态仍用一个5秒速览说明，结束后直接回表盘，不重复开机动画。

不再单独插入选择软件、声音偏好的开场页面；这些设置留在日常设置里。内部步骤编号为兼容已有记录而保留，用户看到的是六组连续引导。

## 共用界面与输入

网页 `WatchFace`、`WatchPages`、`LiveSessions`、`AttentionPage` 和 `DeviceStatus` 同时服务日常页面与教程，练习由独立数据和回调提供。已有会话、待答、麦克风和创建接口不由教程调用。

设备也使用已有的表盘、设置、软件、会话、详情、问题和状态绘制函数。教程入口截住所有业务动作，只处理允许的练习事件。无关按钮淡化，但不禁用指针事件，以免吞掉从按钮上开始的滑动。

触摸浏览器在滑动替换页面后可能省略第一次兼容click；教程会把确定的轻点交给原按钮一次，并吞掉迟到的重复click。读取区消耗冒泡事件时，外层通过捕获阶段记录手指松开，避免一直认为用户按住屏幕而冻结推进。拖动读取仍不选择答案、不确认发送。

## 进度与验证

网页保存版本6，原生保存版本4。已完成、跳过的记录继续保留；旧的未完成记录按当前章节恢复，不能误把旧的简化练习当作新步骤已经完成。

设备新增USB限定的 `TUTORIAL_PREVIEW <step>` 临时预览；`-1`恢复进入前的教程状态。预览期间不写入教程进度，正常用户教程仍保存进度。实机验收通过同一触摸事件入口回放操作，覆盖完整流程，再恢复原来的COMPLETE step10。它不是人手对触摸传感器灵敏度的独立测量。
