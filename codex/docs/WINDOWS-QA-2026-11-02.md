范围：Codex 适配器、本机 Hub、Windows Store 应用工具命名管道、已有配对的实体雪球。
使用原生 Windows 与 Python 3.12；不将该结果扩展为 Linux/macOS 或所有 Windows 分发方式均已验证。

## 软件回归

验证集覆盖 `codex/tests/`、Windows 安全文件与应用管道、BLE 重连、语音接收与调度、
Hub、会话目录、电量/Pet 同步、插件安装与问题路由、完整/Core 打包。
新增原生测试还覆盖目录联接拒绝、中文路径、私有 DACL 读回、收回测试 Everyone 授权、
并发健康探测、管道断线不重发、Windows 禁止 Unix 回退和 Linux 管理入口提前拒绝。

最终回归：198 项测试通过、47 个子测试通过、3 项跳过。跳过项为未分发的私有固件
一致性测试，以及两项缺少 Windows 符号链接权限的测试；真实目录联接拒绝测试已通过。
隔离测试不会向真实聊天发送消息。
完整/Core 构建均验证显式文件清单；本地构建不等于 GitHub Release 已发布。

## 语音投递与隐私

本次 Windows 配置过程中，人工录音、识别文字预览、确认发送新指令和回答准确待答问题
均已有真实接收与 `accepted` 回执。软件测试不能替代后续每次实际投递；桌面问题卡片
自动收起也不是应用接收回答的同一个能力。

公开记录不包含设备身份、BLE 地址、启动 nonce、配对密钥、Hub token、录音、转写正文或用户会话 ID。
原始本机状态与配对文件不打包入仓库。固件下载/缓存逻辑在固定签名测试工件上验证；
由于当前无更新，不声称进行了真实新版固件下载、传输或安装。
