# 正式待答页滑动返回 · 0.18.1

待答正文、长选项、确认回答内容都支持从左向右滑回表盘。上下拖动继续阅读，先上下移动再横向偏移时保持阅读，不误退。拖动选项不会选择或发送；确认答案仍需明确轻点。返回表盘只关闭当前页面，不回答或忽略问题。网页对从按钮开始的手机触摸滑动也已修正。

原因为旧版把阅读区域开始的所有拖动都截获；网页还存在浏览器接管按钮水平手势的问题。本次增加阅读方向判定和锁定，继续沿用32个逻辑像素的有效导航阈值。改动不涉及会话优先级、消息投递、角色资源、连接或节电策略。教程沿用引导路线，不从练习页面发送真实答案。

在旧固件上用隔离问题复现了正文、选项、确认三处不能返回；更新后，同一路径均返回表盘。三处上下阅读与纵向起手锁定通过，确认按钮上的右滑没有产生回答请求。测试数据仅临时经BLE传到显示器，不写真实Hub。最后恢复生产桥接，确认连接健康、停止公开广播、教程记录与显示设置保留。

网页在1440×1050鼠标与430×932触摸环境通过正文/选项/确认页右滑、垂直阅读、斜向/短距离/取消操作、普通选项点击和确认按钮拖动检查，零真实写入、零控制台错误。两种尺寸重新走完教程。另通过142项网页逻辑、4项Sites和4组原生控制器/手势测试。

设备测试是串口输入回放到正常LVGL触摸处理路径，不等于人手传感器体验验收；截图是软件重绘。固件仅更新app1（0x310000），保留原厂系统、NVS、SD资源。详见 [验证记录](../qa/v0.18.1/validation.json)。
