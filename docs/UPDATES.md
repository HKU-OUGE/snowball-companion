# 电脑插件与设备更新

v0.5.0 分发包含 Codex 插件 0.5.0、Claude Code 插件 0.2.0 和 Cursor 插件 0.2.0。它们共享电脑伴随模块，各平台入口、Hooks 和权限边界继续独立。

## 更新电脑插件

从 [Releases](https://github.com/HKU-OUGE/snowball-companion/releases) 核对版本和下载资产，并验证 SHA-256。发布页没有资产时，源码或本地 ZIP 不能当作已发布版本。

沿用 [安装与卸载](INSTALLATION.md) 中本平台的升级流程。先确认服务实际运行目录，不用旧包覆盖较新的共享运行时，不启动第二个 Hub。普通升级保留自己的配对、账号 Pet 和会话设置。Core 与完整版使用相同 Codex 插件 ID；要使用更多角色，用完整版升级同一插件。

## 设备更新流程

下列能力需要设备固件支持认证、暂存和安装调度协议；老固件或未配对设备不会因安装插件而自动获得这些能力。

1. 桥接器从认证连接读取设备版本和更新能力。正常检查间隔约六小时，暂时失败安排重试。
2. 电脑从固定官方 HTTPS 入口检查已发布版本，验证签名、型号、布局、版本、长度及整包 SHA-256 后缓存文件；再次使用缓存时重新校验。
3. 设备支持时，经既有蓝牙连接传输到设备备用区域。状态和待答消息继续服务；语音、供电条件或通信错误可以中止传输。
4. 设备核对完整镜像并决定安装时间。暂存完成不等于立即安装，缺少可靠空闲依据时继续等待。

安装包只内置**验签公钥**。设备配对密钥由接收者自己的配对流程获得，不随仓库或 ZIP 分发；使用者不需要作者的签名私钥。

## 空闲依据与安装时机

兼容设备通常要求主表盘保持空闲约五分钟，并满足供电、暂存完整性等条件；新任务、待答和用户操作会影响计时。具体条件与设置由已安装设备固件决定。

本次可靠活动核查面向**本机 Codex Desktop**，结合新鲜 Hook、独立运行状态、完整本地会话目录及问题状态。目录变化、状态缺失或观察过期不当作“肯定空闲”。活跃期间不额外读取历史；冷会话核查每轮有数量限制。

这不是 Claude、Cursor、远程会话或独立 CLI 的全局活跃性证明。Claude／Cursor 的单独 Hub 不启动 Codex 轮询；没有受支持的完整空闲证据时，不会据此自动安装。混合软件使用时，不能把“Codex 空闲”理解为“所有 AI 软件都空闲”。

## 蓝牙与 Wi-Fi

既定设备策略是蓝牙可用时优先蓝牙，Wi-Fi 作为回退。无线回退、断点恢复、升级期间暂停／恢复蓝牙和安装保护由兼容设备固件负责；这个电脑包不会替设备配置 Wi-Fi 或部署远程服务。

本次包含电脑的蓝牙更新客户端，不包含网页应用、设备固件、Cloudflare 服务端、部署凭据或新增局域网网关。已有远程连接服务独立管理。

## 怎样确认成功

- **下载完成**：电脑取得并验证了镜像。
- **已暂存**：设备确认备用镜像已校验，当前可能仍运行旧版。
- **已安装**：设备启动到新版本，并完成自身健康确认。

ZIP 构建成功、发送结束或 Hub 在线均不能证明设备已安装；需核对设备更新页或经过认证的版本信息。没有 SD 卡／缓存损坏时的恢复能力以设备固件为准。插件不会擦除 SD 资源、写入 eFuse 或绕过签名检查。

本次仓库准备提供确定性打包和隔离主机回归，不能代替接收者宿主安装、真实 Hook 或设备验收，也不代表已部署 USB 安装盘固件。
