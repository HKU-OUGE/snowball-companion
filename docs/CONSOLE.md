# 雪球控制台：连接设备与 Wi-Fi 配网

从分发包 v0.5.4 开始，控制台网页、Python 服务和启动器随包提供。无需安装 Node.js、Vite，
也无需记住开发电脑上的端口。控制台只监听本机回环地址，启动器自动找到正确页面。

## 如何打开

先把完整 ZIP 解压到电脑的固定目录，不要从 USB 安装盘或 ZIP 预览窗口里运行。

| 分发包 | 控制台目录 | Windows | Linux / macOS |
| --- | --- | --- | --- |
| Codex / Codex Core | `codex/` | 双击 `Open-Snowball.cmd` | 运行 `./open-console.sh` |
| Claude / Cursor | `console/` | 双击 `Open-Snowball.cmd` | 运行 `./open-console.sh` |

Codex 的 Windows 安装器还会创建桌面 **雪球控制台** 快捷方式。已安装 Codex 插件时，
也可以运行 Setup 并说“打开雪球控制台”。普通双击入口只打开页面；通过 Skill 的 `--setup` 入口会自动开始配置，账号 Pet 由 agent 的真实 Pets 接口完成。网页不能批准 Hooks，也不重置配对或安装固件。新电脑仍需先安装 Python 3.12 / 3.13；首次准备可使用互联网和已挂载的 SD 资源。

完整仓库中的控制台源码和入口在 `codex/`。Claude / Cursor 分发包由同一份已列入白名单的
公共运行时代码生成 `console/`，不会覆盖各适配器原有的 `runtime/`。
控制台可以独立运行，不要求安装 Codex。控制台的 Windows 兼容性不等于 Claude / Cursor
适配器的原生 Windows Hooks 已受支持；两者的支持范围分别核对。

## 一条主线，明确看哪里

完整首次使用入口是 [START-HERE](START-HERE.md)。控制台每页上方显示当前应看电脑还是雪球；所有配置选择和进度留在网页；agent 在后台执行，只有宿主授权仍使用宿主自身的提示。

1. **01 自动配置｜看电脑控制台**：Skill 打开后自动准备连接环境、当前用户登录自启动、连接服务、本地语音和 Pet。已有服务、模型和配对复用。网页可更换语音模型和角色，也可重试或跳过可选项目；Pet 以当前账号的实际回执为准。
2. **02 连接雪球｜留在电脑控制台**：接 USB 数据线、核对串口。首次教程中的 0.27.0+ 设备由安装程序自动开启限时配对；唯一未绑定设备自动绑定，多设备时选择目标串口。先尝试真实绑定，只有设备明确要求本机确认时才提示去“连接电脑”点“开启配对”。无需先勾选“已开启配对”；串口无回复或权限问题也不会要求点击设备。系统蓝牙“已配对”不能代替应用绑定。
3. **03 确认同步｜先看电脑，再看雪球**：查看后台、设备身份、蓝牙认证和新鲜状态回执。必要时回 AI 会话正常使用一次，再回此页检查；不要用演示数据验证真连接。然后看雪球的会话列表核对当前聊天；设备初次教程连接成功后自动继续，依次练习设置、会话、待答、状态。操作成功后自动继续，不再来回切换三份教程。
4. **04 网络设置｜回电脑按需设置**：基础蓝牙连接已可以使用。需要 Wi-Fi 才准备局域网入口、去雪球打开「连接电脑 → Wi-Fi 配网」，再回控制台输入 2.4 GHz 名称和密码。语音和桌宠已集中在「自动配置」，无需再回会话分别下指令；它们可在网页跳过。

连接检查区分别显示 **设备状态回执、运行中 Hub 的 Codex 指令通道、当前问题可回答情况**。语音以实际模型健康检查为准，尚未就绪时显示对应进度，不能因蓝牙正常就宣称语音可用。没有问题表示未实测回答；设备教程的独立练习题不会发给真实会话。

默认“自动切换 · 蓝牙优先”。蓝牙正常时 Wi-Fi 休眠；要立即验证局域网同步，可在设备
Wi-Fi 页选择“优先 Wi-Fi”。远程 HTTPS 地址是可选高级项，仍需要电脑云连接
和设备身份；填写域名不会自动开通云服务。设备确认保存前，不把网页提交成功当作配网成功。

## Windows 日常使用

如果蓝牙正常但设备待答页只有「稍后处理／忽略提醒」，请核对 [Windows 回答接口](../codex/plugins/xueqiu-status/skills/setup/references/windows-send.md)。
v0.5.5 修复登录后台无法继承 Codex 端点的问题；旧 Hub 需要按归属核对后重启一次。控制台连接正常不等于回答接口已就绪。

自动配置会注册或复用 **Windows 当前用户登录自启**；Linux 使用已有或归属明确的 systemd 用户服务。macOS 尚未实现这一自动注册步骤，网页明确显示不适用。
登录后后台启动，关闭浏览器不会停止同步。睡眠和关机时不能同步。重复打开控制台会复用
正在运行的实例；后台不会打开第二个浏览器窗口或重复绑定设备。

如果设备已加入 Wi-Fi，却停在连接电脑网关，先核对电脑与设备是否同局域网。在可信的
家庭网络上，可以展开控制台的 Windows 排错项，点击“允许本安装的局域网连接”。
Windows 会显示 UAC 确认；取消不会被写成成功。规则仅允许本安装的 Python 程序、
专用网络、局域网来源、TCP 4193，不关闭防火墙，也不放行控制台端口。

控制台不会自动迁移已绑定网关的身份。如果电脑局域网地址改变且出现身份冲突提示，
先保留当前配置并通过 Setup 核对迁移，不要删除全部凭据或反复创建共享服务。

## 数据和生命周期

- Wi-Fi 密码在网页内仅用于当次提交，提交后清空；不写浏览器存储、网址或日志。标签页只保存一小时有效的控制台访问令牌，且与其他本机端口隔离。
- 蓝牙配对和网关凭据在接收者的私有目录生成。Windows 使用并读回验证用户/SYSTEM ACL，
  不依赖 Unix 的 `chmod`。设备是否持久保存由实际硬件密钥状态决定，临时配置会明确显示。
- 网页控制台与局域网网关分离：网页只允许本机访问；局域网接口只接收设备的认证协议，
  不开放 Hub 管理接口或任意命令执行。
- 控制台的依赖、入口收据和运行状态放在用户目录，不随公开安装包分发。原有固定目录
  的 `.venv` 可复用；新环境位于用户的 `.local/share/xueqiu/console-venv/`。
- 普通插件卸载保留共享服务、配对和控制台。要移除整个产品时，再核对登录任务、控制台
  进程、桌面快捷方式和本安装创建的防火墙规则；保留其他安装和用户凭据，除非用户明确
  要求清除。Windows 防火墙辅助脚本支持显式 `-Remove`，只处理相同安装标记的规则。
- 安装新版电脑插件不会自动替换设备 SD 安装盘，也不会刷写设备固件。

## 自动配置与模型选择

通过插件 Setup 打开时自动开始；普通桌面入口不擅自安装，用户可在页面点「开始自动配置」。中断后保留已完成项，失败项可以单独重试，进度不会把下载完成等同于服务可用。Pet 的网页状态只接受 agent 经真实 Pets 服务核验后的回执；如果 agent 已离开，网页显示等待 agent 接入，不显示虚假的安装成功。

新安装默认 Base（约 148 MB），Tiny（约 78 MB）和 Small（约 486 MB）可选；已有 Small 沿用。模型先复用电脑缓存，大文件优先联网，小文件优先 SD；网络不可用时回退 SD，所有来源均经 SHA-256 校验。模型与 Python 环境分别计大小；卡拔出后识别仍可用。旧版已运行的语音进程若不支持安全热加载，会明确报告需要更新，不会强杀正在识别的进程。

## SD 卡离线依赖

整卡资源包可同时保存 Windows x64、Linux x64、macOS Apple Silicon/Intel 的 Python 3.12/3.13 依赖。网页按真实系统、芯片和 Python 版本选择，校验每个文件后先导入电脑缓存，再使用 `--no-index --require-hashes` 安装；卡拔出后识别和同步仍可使用。插件 ZIP、安装说明优先从 SD 获取；先复用电脑上已校验的缓存。其余不超过 1 MiB 的小文件优先 SD，模型、Python 和较大依赖优先互联网，网络不可用或连续无数据时回退 SD。持续有数据的下载不受固定总时长中断。仅获取当前系统、Python 版本和当前步骤需要的依赖；语音模型只获取选中项。Linux 的 BlueZ、系统动态库及各系统蓝牙驱动由操作系统提供；AI 软件登录和宿主授权不包含在资源包内。

`offline/python/` 提供经上游摘要核验的 CPython 3.13.18 独立运行时。系统 Python 缺失或缺少 venv/ensurepip 时，agent 可运行 `companion/offline_resources.py --prepare-python` 准备到当前用户私有目录，再使用返回的解释器继续配置，不修改系统 Python。Mac 登录自启动仍显示不适用。

## 独立安装向导

v0.7.0 安装程序直接打开功能选择页，无需 Skill。选择软件、USB 绑定、自启动和语音模型后再执行安装；未选择的功能不会删除现有配置。授权请求通过 Windows UAC 或 Linux polkit 弹出系统窗口。完成后进入同一控制台的连接、同步、Wi-Fi 页面。账号 Pet 需要宿主授权，不阻塞实体设备安装。
