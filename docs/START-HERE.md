# 第一次使用 Snowball Companion

**配置时看电脑的「雪球控制台」，连接后回雪球练习。** Agent 从 Skill 打开网页后，会自动准备连接环境、登录自启动、本地语音与账号 Pet。选择、进度、重试和跳过都留在网页；会话不再另起一份配置清单。无需同时跟着三份教程；控制台每一步会告诉你现在看哪里、完成后回哪里。

只想用 Codex 账号桌宠时，安装后说“安装雪球桌宠”即可，不需要 USB、蓝牙或实体设备。Claude Code / Cursor 插件主要同步状态，不会创建 ChatGPT Pet。

## 先在电脑安装，打开控制台

从 [最新正式 Release](https://github.com/HKU-OUGE/snowball-companion/releases/latest) 下载对应 ZIP，复制到电脑固定目录后解压全部文件。不要长期从 USB 安装盘、ZIP 预览或临时目录运行。Core 只包含雪球基础 Pet，完整 Codex 包有更多角色；两者选一个即可。

| 使用的软件 | 安装插件 | 随包控制台入口 |
| --- | --- | --- |
| Codex / Codex Core，Windows | 在 `codex/` 运行 `install-windows.ps1` | 双击 `codex/Open-Snowball.cmd`，或桌面「雪球控制台」 |
| Codex，Linux / macOS | 在 `codex/` 执行 `./install.sh` | 执行 `codex/open-console.sh` |
| Claude Code，本地 Linux / macOS | 按 `claude/README.md` 安装，运行 `/snowball-companion:setup` | `console/open-console.sh` |
| Cursor | 按 `cursor/README.md` 安装本地插件并运行 Setup | 完整包的 `console/` 启动器 |

Windows 请预装 Python 3.12 / 3.13，使用原生 PowerShell 流程，不执行 Unix shell 命令。已有服务先看 [安装与升级](INSTALLATION.md)，避免启动重复后台。Claude / Cursor 控制台可在 Windows 运行，不表示各适配器已支持原生 Windows Hooks。

安装后让宿主加载插件；若宿主提示审阅 Hooks，由你确认一次。已有聊天尚未加载插件时才用新聊天验证，不要每个聊天重复安装。Codex Setup 可以说“配置 Snowball Companion，打开控制台并自动配置”；无需记端口或启动开发服务器。

## 跟着同一条主线

| 阶段 | 现在看哪里 | 做完去哪里 |
| --- | --- | --- |
| **01 自动配置** | 看控制台的逐项进度。Agent 自动准备环境、登录自启动、连接服务、语音和 Pet；已有配置直接复用。 | 留在控制台，进入「连接雪球」 |
| **02 连接雪球** | 接 USB 数据线并核对串口。看雪球「连接电脑」，核对蓝牙名称，点「开启配对」。 | **回电脑控制台**，勾选确认并绑定；等待实际蓝牙认证 |
| **03 确认同步** | 控制台：分别看后台、身份、蓝牙和状态回执。必要时回 AI 会话正常使用一次，再回控制台检查。 | **看雪球**：上滑核对会话；首次教程点「继续练习」 |
| **设备练习** | 只看雪球：摸摸、吃西瓜、设置、会话、待答、状态。做对后会开心回应并自动继续。 | 回到表盘日常使用，或按需要回控制台 |
| **04 网络设置** | 控制台：按需配置 Wi-Fi；语音模型与 Pet 选择都在「自动配置」。 | 配完回「确认同步」查看结果 |

设备普通路径是「设置 → 更多 → 连接电脑」。首次教程已在连接页面时，不必退出重找。
「开启配对」窗口约两分钟，旧固件可能写「开始配对」。过期时，电脑准备好后重新开启即可。
**只在电脑系统蓝牙里看到“已配对”不算完成绑定。** USB 用于首次确认身份，日常状态同步不必一直连 USB。

教程可选择「暂不连接，先练习」，但这只完成操作练习，不代表设备已连接。开发用圆屏网页演示中的“模拟连接”同样不连接实体设备；真实配置使用随包控制台。

## 完成到哪一步，分别看结果

- 插件启用、真实事件到达、后台服务健康、设备收到状态是不同层次。正常连接且没有任务时，显示「等待新任务」是正常的。
- 基础蓝牙同步不要求 Wi-Fi。需要时再看 [控制台配网说明](CONSOLE.md)。密码在本机页面输入，不必发到会话里。
- 想在设备回答问题或追加任务，还要检查投递通道。Windows 已连接但只有「稍后处理／忽略提醒」时，看 [回答通道排错](../codex/plugins/xueqiu-status/skills/setup/references/windows-send.md)。
- 本地语音在「自动配置」准备；可选 Base、Tiny、Small，遇到问题查看 [语音说明](../codex/plugins/xueqiu-status/skills/setup/references/speech-setup.md) 核对当前状态。识别文字正确后仍需在设备确认发送；教程回答不验证真实投递。

若任一步中断，重新打开桌面「雪球控制台」或包内启动器，接着当前阶段继续；不用重置配对。包不含设备固件和个人密钥，也不会自动刷机。

## USB 安装盘与后续更新

在支持安装盘功能、且 SD 卡里已有公开安装资源的设备上，可以不经过网页下载，直接用数据线复制插件：

1. 用支持数据传输的 USB 线把雪球接到电脑。
2. 在设备进入 **设置 → 连接电脑 → 获取插件**。这里也有公开安装指南二维码。
3. 点 **USB安装盘**，等待准备完成。电脑会出现名为 `SNOWBALL` 的只读磁盘。
4. 打开 `START.HTM` 看离线说明，或复制 `CODEX.ZIP`、`CLAUDE.ZIP`、`CURSOR.ZIP`。`CODEX.ZIP` 是只包含雪球的 Core 版；完整角色库使用上方线上下载入口。
5. 把 ZIP 复制到电脑固定目录，完成复制后弹出磁盘，或在设备点 **退出安装盘**。设备会重启，恢复正常连接；然后在电脑解压并按包内教程安装。

安装盘模式会暂时替代 USB 串口。语音录音、资源上传或固件更新正在进行时，先等当前操作结束再打开。普通连接数据线不会自动运行安装脚本，也不会把整张 SD 卡挂载给电脑。

这个只读盘只包含公开的插件包、说明和校验文件。Wi-Fi、配对密钥、会话及其他 SD 资源不在安装盘里。主机不能通过它更改设备文件。Python、对应 AI 软件和第三方依赖没有一并内置，因此不承诺在全新电脑上完全离线完成所有依赖安装。

这项功能需要兼容的设备固件和安装盘镜像；只有电脑插件 ZIP 或 USB 串口不能证明设备已经支持。安装盘里的包可能早于线上版本，需要最新版时查看 [Releases](https://github.com/HKU-OUGE/snowball-companion/releases)。

电脑插件更新与固件更新分开处理，见 [更新说明](UPDATES.md)。普通卸载只移除指定平台插件；账号 Pet、其他平台、设备配对和共享服务分别管理。

### 使用旧离线安装包后

设备 SD 安装盘可能仍保存较早的离线包。本次电脑插件源码更新不会自动替换这份安装盘。完成离线安装后，请联网检查 GitHub Release，并按 [安装与升级](INSTALLATION.md) 更新对应插件；确认电脑桥接服务已使用新版运行时，再在新固件上使用手动蓝牙更新。不要删除旧配对或重复启动 Hub。

## 语音模型与 SD 卡

新用户默认多语言 Base，模型文件约 148 MB；Tiny 约 78 MB，Small 约 486 MB。已有有效模型会沿用，不自动降低识别规格。模型大小不包括 Python 识别环境；是否听得准还需要用自己的录音验证。所有识别都在电脑进行，ESP32 负责录音与显示。

若 SD 卡包含 `Snowball-Setup/speech-models/base/`，先通过设备的整卡 USB 存储模式或读卡器连接电脑。在「自动配置」选择 Base 或重试语音，插件会优先检查这组固定版本的文件和 SHA-256，复制到电脑缓存后使用，无需再次下载模型。首次安装 Python 依赖仍可能需要联网。导入完在电脑安全弹出卡，退出存储模式，恢复正常设备连接。只读的 8 MiB 插件安装盘不包含这个 148 MB 模型。

整卡 USB 存储需要对应固件，容量取决于实际 SD 卡。电脑可读写全部卡内文件；期间设备暂停卡内资源和日志访问，安全弹出后重启恢复。不要在电脑格式化这张资源卡或删除 `snowball/` 角色资源。电脑插件更新不会自动烧录此功能。
