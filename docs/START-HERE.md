# 第一次使用 Snowball Companion

**配置时看电脑的「雪球控制台」，连接后回雪球练习。** Agent 从 Skill 打开网页后，会自动准备连接环境、登录自启动、本地语音与账号 Pet。选择、进度、重试和跳过都留在网页；会话不再另起一份配置清单。无需同时跟着三份教程；控制台每一步会告诉你现在看哪里、完成后回哪里。

只想用 Codex 账号桌宠时，安装后说“安装雪球桌宠”即可，不需要 USB、蓝牙或实体设备。Claude Code / Cursor 插件主要同步状态，不会创建 ChatGPT Pet。

## 先在电脑安装，打开控制台

新用户从 [最新 Release](https://github.com/HKU-OUGE/snowball-companion/releases/latest) 下载对应系统的 **Snowball-Setup** 安装程序。Windows 双击 EXE；macOS 打开 DMG 内的安装 App；Linux 解压后运行 `Install-Snowball.sh`。详细入口、系统限制及授权提示见[安装程序说明](../installer/README.md)。无需预装 Python、Node.js、Git 或调用 Skill。

网页先让你勾选软件、设备连接、登录自启动和语音模型，再点“安装所选功能”。未选项目不会安装，不会删除原有配置。接上 USB 后自动尝试绑定；语音模型可以晚些安装。之后从开始菜单或应用列表的 **Snowball Console** 再次打开。

需要手动命令或已有 SD 插件 ZIP 的用户，仍可按[安装与升级](INSTALLATION.md)使用旧入口。插件 ZIP 优先从 SD 获取，旧包不得覆盖新运行时。传统 ZIP 不含 Python；新的系统安装程序已内置 Python。宿主提示审阅 Hooks 时由用户确认，不自动修改信任。

## 跟着同一条主线

| 阶段 | 现在看哪里 | 做完去哪里 |
| --- | --- | --- |
| **01 自动配置** | 看控制台的逐项进度。勾选所需功能后安装环境、插件、连接服务和可选语音／自启动；已有配置优先复用。 | 留在控制台，进入「连接雪球」 |
| **02 连接雪球** | 接 USB 数据线；安装程序识别唯一串口，在0.27.0+首次教程中自动开启配对。先尝试自动绑定，只有设备明确要求本机确认才提示点击「开启配对」。 | **留在电脑控制台**，唯一新设备自动绑定；多设备才需选择串口，等待实际蓝牙认证 |
| **03 确认同步** | 控制台：分别看后台、身份、蓝牙和状态回执。必要时回 AI 会话正常使用一次，再回控制台检查。 | **看雪球**：上滑核对会话；首次教程连接成功后自动继续顺序练习 |
| **设备练习** | 只看雪球：依次练习滑动查看设置、会话、待答和状态。做对后会开心回应并自动继续。 | 回到表盘日常使用，或按需要回控制台 |
| **04 网络设置** | 控制台：按需配置 Wi-Fi；语音选择在安装向导；设备宠物在设备设置中选择。 | 配完回「确认同步」查看结果 |

设备普通路径是「设置 → 更多 → 连接电脑」。首次教程已在连接页面时，不必退出重找。
「开启配对」窗口约两分钟，旧固件可能写「开始配对」。仅在电脑已经尝试绑定、设备明确要求确认后，才需要手动开启。
**只在电脑系统蓝牙里看到“已配对”不算完成绑定。** USB 用于首次确认身份，日常状态同步不必一直连 USB。

首次教程必须先完成连接，再按顺序练习；不能中途跳过或跳步骤。开发用圆屏网页演示中的“模拟连接”同样不连接实体设备；真实配置使用随包控制台。

## 完成到哪一步，分别看结果

- 插件启用、真实事件到达、后台服务健康、设备收到状态是不同层次。正常连接且没有任务时，显示「等待新任务」是正常的。
- 基础蓝牙同步不要求 Wi-Fi。需要时再看 [控制台配网说明](CONSOLE.md)。密码在本机页面输入，不必发到会话里。
- 想在设备回答问题或追加任务，还要检查投递通道。Windows 已连接但只有「稍后处理／忽略提醒」时，看 [回答通道排错](../codex/plugins/xueqiu-status/skills/setup/references/windows-send.md)。
- 本地语音在「自动配置」准备；可选 Base、Tiny、Small，遇到问题查看 [语音说明](../codex/plugins/xueqiu-status/skills/setup/references/speech-setup.md) 核对当前状态。识别文字正确后仍需在设备确认发送；教程回答不验证真实投递。

若任一步中断，重新打开桌面「雪球控制台」或包内启动器，接着当前阶段继续；不用重置配对。包不含设备固件和个人密钥，也不会自动刷机。

## USB 安装盘与后续更新

在支持安装盘功能、且 SD 卡里已有公开安装资源的设备上，可以不经过网页下载，直接用数据线复制插件：

1. 用支持数据传输的 USB 线把雪球接到电脑。
2. 打开 **设置 → USB存储**；固件 0.28.5 起，“连接电脑 → 获取插件”里的 USB 入口也使用同一整卡目录。
3. 开启后，电脑会显示 SD 卡的实际容量。打开根目录 `START.html`，或 `Snowball-Setup/START.html`。
4. 复制对应的 `Snowball-Codex.zip`、`Snowball-Codex-Core.zip`、`Snowball-Claude.zip` 或 `Snowball-Cursor.zip` 到电脑固定目录，再解压安装。Core 和完整 Codex 包选一个。
5. 资源导入完成后，在电脑安全弹出磁盘。设备退出存储模式、恢复串口后，继续网页里的 USB 自动绑定。

USB 存储期间会暂停卡内资源和日志访问，电脑可读写整张卡。只复制需要的安装资源，不格式化卡或删除 `snowball/`。普通接线不会自动运行安装程序。

旧固件的“USB安装盘”仍可能导出独立的 8 MiB 只读镜像，里面的包不会随整卡目录更新。
遇到这个入口时改用 **设置 → USB存储** 获取当前包。插件版本可在 ZIP 的 `BUNDLE.json` 核对；
SD 优先不表示允许旧包覆盖较新的电脑运行时。卡内缺少目标版本时再从网络获取。

电脑插件更新与固件更新分开处理，见 [更新说明](UPDATES.md)。普通卸载只移除指定平台插件；账号 Pet、其他平台、设备配对和共享服务分别管理。

### 使用旧离线安装包后

设备 SD 安装盘可能仍保存较早的离线包。本次电脑插件源码更新不会自动替换这份安装盘。完成离线安装后，请联网检查 GitHub Release，并按 [安装与升级](INSTALLATION.md) 更新对应插件；确认电脑桥接服务已使用新版运行时，再在新固件上使用手动蓝牙更新。不要删除旧配对或重复启动 Hub。

## 语音模型与 SD 卡

新用户默认多语言 Base，模型文件约 148 MB；Tiny 约 78 MB，Small 约 486 MB。已有有效模型会沿用，不自动降低识别规格。模型大小不包括 Python 识别环境；是否听得准还需要用自己的录音验证。所有识别都在电脑进行，ESP32 负责录音与显示。

若 SD 卡包含 `Snowball-Setup/speech-models/` 下的对应模型目录，先通过设备的整卡 USB 存储模式或读卡器连接电脑。在「自动配置」选择对应模型或重试语音，安装器会先复用电脑缓存；模型大文件优先联网，小文件优先 SD，网络不可用时使用卡内相同固定版本。各来源都校验 SHA-256，并复制到电脑缓存后使用。连接和语音依赖分步获取。导入完在电脑安全弹出卡，退出存储模式，恢复正常设备连接。只读的 8 MiB 插件安装盘不包含这个 148 MB 模型。

整卡 USB 存储需要对应固件，容量取决于实际 SD 卡。电脑可读写全部卡内文件；期间设备暂停卡内资源和日志访问，安全弹出后重启恢复。不要在电脑格式化这张资源卡或删除 `snowball/` 角色资源。电脑插件更新不会自动烧录此功能。
