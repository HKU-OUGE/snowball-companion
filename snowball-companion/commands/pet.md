---
name: snowball-pet
description: List Snowball Companion characters or select one the user explicitly requests.
---
Locate this plugin's root. Run `python3 <plugin-root>/scripts/control.py characters`
to list IDs. Only if the user explicitly names a character, run
`python3 <plugin-root>/scripts/control.py pet <character-id>` with that ID.
Report the Hub receipt as a request, not proof that the physical device loaded it.
